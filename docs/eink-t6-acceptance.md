## 改动

- 正式练习、背诵 / 卡片及 AI 临时练习的底栏两侧加入「上屏 / 下屏」，与中间的提交、判分、下一题保持同行。没有作答按钮时，中间显示「阅读本题」。常规字号下不另加一行。
- 翻屏按固定顶栏下方、底栏和键盘上方的实际可读高度计算步长，保留约两行重叠（最多可读区的三分之一），直接移动窗口，不使用平滑滚动。每次操作重新计算，适应字号、公式排版和视口变化；到边界显示禁用的「页首 / 页末」。
- 仅改变阅读位置，不重建题目、不等待答案草稿保存、不提交 / 判分 / 切题或写入学习进度。填空输入焦点和草稿保留；手动滑动和宽公式自身横向滚动仍可使用。
- 同题返回和下一题沿用 T5 的位置规则。离开页面时解除旧按钮监听；字体晚到的恢复回调不能覆盖新一次翻屏操作。

## 用户测试清单

使用已有题库即可，无需重新导入。长内容不足时可在已有长题 / 背诵中验收对应场景；没有的题型或 AI 临时题组可以说明跳过。

1. **长题与边界**：连续点「下屏」读到最后，再用「上屏」返回。前后屏保留少量重叠，题干、选项和解析没有漏行，顶栏和底栏持续可用。页首 / 页末禁用，短题能完整容纳时两侧均禁用。手动滑动仍可用，边界状态随之更新。
2. **阅读与作答分开**：先选一个答案或填写草稿，再来回翻屏。选择 / 草稿保留，题号和作答统计不因翻屏改变；提交或自判后可继续阅读解析，只有中间「下一题 / 完成」推进练习，新题从顶部开始。
3. **背诵 / 卡片**：展开前后均可翻屏；长提示、正文、要点或背面内容能读完。展开内容不会误切下一项；两侧阅读按钮与中间学习按钮不粘连，常规字号下同行。
4. **公式**：宽公式可以单独左右查看，按屏上下移动后横向位置仍保留；高公式可以分屏读全，末行和随后正文都能到达。
5. **字号与键盘**：如使用大字，确认步长适应当前可读区，内容无遗漏。填空时打开 / 关闭键盘并尝试翻屏，检查草稿保留、底栏可点、没有持续跳回原位置或被遮住的末尾内容。编辑 / 笔记返回仍回到同题的合理位置。
6. **已有 AI 临时题组（可选）**：翻屏保留临时答案和本组进度；判分后读解析、明确点下一题才推进，正式题库统计不增加。没有已有题组时跳过，不需调用在线 AI。

自动化浏览器检查不能代替 PA6 WebView / 汉王输入法验收。实体墨水屏的残影、闪烁和刷新速度由用户观察，ADB 截图不验证这些指标。
