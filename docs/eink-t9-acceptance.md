# T9：实体键验证与适配调查

日期：2026-10-10。用户明确要求从 T8 继续 T9，并反馈实体屏闪烁一直存在；闪烁留待 T10 调查，本项仅确认实体输入能力。

## 结论

用户观察机身后明确回复「只有电源键」。本台 HANVON Clear6 Plus（PA6 / PA6GB32）没有可用于阅读翻屏的机身翻页键或音量键，因此本项不新增实体键映射。电源键保留系统休眠 / 唤醒功能，阅读继续使用现有触屏上屏 / 下屏。

这属于「已调查、无可适配的机身翻页键」，不属于「实体翻页键适配成功」。外接键盘 / 遥控器本轮未连接或测试，也未新增对应支持。以后若出现实际可用的新输入设备，需要采集真实按键事件后单独适配，并检查输入框聚焦时不会误翻屏；不能把 ADB 注入的事件作为机身按键存在的证据。
