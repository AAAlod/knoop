## 改动

- 搜索等待期间使用原生 `disabled` 禁用旧结果、搜索练习入口、题号跳转与显示更多；不依赖 WebView 83 缺少的 `inert`。保留旧列表及操作区的位置，避免等待时移除按钮造成额外高度变化。
- 事件入口和异步读取之后检查当前搜索动作是否仍有效。查询修改、结果重画或离开页面会使旧动作失效；即使等待保存结束后查询又改回原词，也不会补执行旧的跳转。
- 中文组合输入期间显示「输入中…」，候选提交后再按 180 ms debounce 更新结果。连续输入仅发布最后查询，保留搜索输入节点、焦点与光标；离开页面取消待执行搜索。
- 每批仍显示 100 项，搜索后的题号保留原目录编号。正式会话跳题、顺序 / 随机搜索练习、背诵搜索维持原来的进度及判分语义。
- 开发依赖固定 Playwright 及锁文件，增加 `setup:ui` / `test:ui`，把既有 UI、黑白、间距、底栏与搜索专项接入 `check:ci`。GitHub Actions 安装对应 Chromium / 系统库，失败时保存 UI 证据。运行方法见 [UI 自动检查](ui-testing.md)。

## 用户手动测试

使用设备上已有题库即可。可在「新练习 → 选择范围 → 下一步 → 目录」测试新练习目录；当前会话目录从「继续」后的顶栏目录进入。

1. **中文输入**：在目录搜索框用中文输入法输入一个题目里已有的词。选候选、继续输入、收起 / 打开键盘，输入和光标应正常，结果最终对应完整词；不会自行跳到题目或返回上页。
2. **快速修改与清空**：连续换两个关键词，再试一个不存在的词及清空。数量与列表只对应最后输入；无匹配时没有搜索练习按钮，清空后恢复完整目录。
3. **等待期间误点**：中文候选尚未提交，或快速改词后立即点旧结果、顺序 / 随机入口、跳转、显示更多，或按键盘确认。等待期间不能启动旧练习或跳题；结果更新后按钮可正常使用。无需为了捕捉短暂的 180 ms 状态反复测试，中文组合输入期间同样覆盖禁用状态。
4. **匹配题与返回**：搜索出某一道题，记住目录原题号后打开，题目和原题号应对应；返回目录后搜索词和筛选结果仍在。返回上一页 / 首页不会稍后被搜索更新带回目录。
5. **搜索练习与背诵**：在新练习目录分别尝试搜索后的顺序与随机入口，只包含匹配题；在背诵目录搜索材料内容并开始，仍进入背诵流程。无需作答提交。
6. **当前会话跳题**：从当前会话目录搜索，再选匹配题，进入同一会话的正确题号；中文候选期间的误点 / 确认不会提前跳题。仅搜索或定位不应增加答题 / 正误统计。
