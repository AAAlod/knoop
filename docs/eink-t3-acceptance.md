# T3：底栏、同行菜单与软键盘可达性验收

用户于 2026-10-10 确认通过。

日期：2026-10-09。前置条件：用户确认 T2 基本通过，要求更多操作展开优先同行、减少额外高度和滚动，并授权并入 T3。依据 [任务记录](eink-task-tracker.md) 的 T3 / Review R3、R4。

## 本轮改动

- 更多操作直接加入收藏 / 笔记所在按钮行，空间足够时同行；提供「收起」按钮。窄屏、大字或较长状态文字确实放不下时才换行，触控区域仍至少 48 CSS px。
- 展开后仅在操作被底栏挡住时，按遮挡距离立即调整阅读位置，不进行平滑滚动；不重建整页，不更改答案、排除、判分或进度。
- 通用作答、范围及表单底栏按实际高度给正文留白，底栏换行、字体或视口变化后重新测量。页面及单操作栏通过明确类名表达状态，移除关键布局的 `:has()` 依赖。
- Android 显式使用 `adjustResize`。支持可视视口变化时将底栏放在键盘上方；输入框聚焦或键盘开关时检查遮挡，避免要求用户猜测被挡住的输入区域。
- 表单文本域高度不超过当前可用视口，长内容保留在可滚动文本域内；键盘收起后恢复可用高度，保留草稿和光标。

稳定顶栏与返回阅读位置仍属于 T5；本项不把截图检查当作实体墨水屏刷新、闪烁或残影验证。

## 手动测试清单

1. **同行展开**：继续练习，点击更多；PA6 默认字号下，收藏 / 笔记 / 编辑 / 斩杀 / 标记问题 / 收起应在同一行。点击收起能恢复，不改变已有选项或进度。较大字号确实放不下时允许换行。
2. **展开可见**：在靠近页面底部时展开，新增操作应完整出现在底栏上方，必要时只小幅自动调整，无需另拖一屏寻找菜单。编辑和标记问题可进入并取消返回，不必执行斩杀。
3. **编辑最后字段**：进入编辑，滚到最后的解析；最后一行和保存操作可达。点解析唤起键盘，输入几行测试文本，检查光标所在内容与保存按钮；收起 / 再打开键盘，内容仍在。取消返回，不必保存测试文本。
4. **笔记键盘**：打开笔记，点击输入区；若汉王先显示输入法工具条，点击其键盘图标展开完整键盘。输入多行并到最后一行，检查输入位置和保存按钮可见；收起键盘后内容保留。新笔记的单个保存按钮应占满操作栏可用宽度。
5. **审核与多按钮底栏**：标记问题页面滚到审核意见，键盘开关后意见和操作可达；已有审核的多个操作按钮如果换行，正文最后一项仍能滚到底栏上方。没有已有审核时，此场景可留待有数据再测，自动化已覆盖。
6. **作答与范围**：填空题打开 / 收起键盘，输入不丢、提交可达；选范围时最后一个章节不被下一步栏挡住。提交答案会正常写入学习记录，可按自己的测试需要操作。
