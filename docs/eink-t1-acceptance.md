# T1：黑白视觉与状态可辨识

日期：2026-10-09。关联 [任务记录](eink-task-tracker.md)。状态：已构建、覆盖安装并完成截图检查，等待用户手动验收。

## 本轮范围

- 白底、黑字、深灰次级信息与清晰边框，移除装饰阴影和底栏透明度。
- 主动作黑底白字；已选题型以反色区分；选项选中保留黑底字母标识；排除使用删除线和虚线边框，保持文字不淡化；正误继续显示“选对 / 错选 / 漏选 / 正确答案”。
- 禁用按钮使用可读的文字与虚线轮廓，继续保留真实 disabled 语义；输入内容不使用整体透明度淡化。
- 复选框、单选框有显式黑白外观，不依赖旧 WebView 的 accent-color；焦点使用兼容的 `:focus` 黑色外框。
- Android 日间 / 夜间资源均使用浅色主题、白色窗口与系统栏，关闭系统自动深色处理；HTML 声明浅色。
- 截图测试加载应用实际导入的 CSS 与本地 KaTeX 字体，补充墨水屏状态测试。公式解析失败的文字使用黑色，不改变题库中的公式原文。

本轮保留 `0.1.12 / 113`，通过任务 APK 文件名和摘要识别。没有数据库迁移、题库协议变更或真实 AI 请求。

## 手动测试清单

使用设备上已有的合成题库即可。可以从“新练习”选择整库，再通过题目顶栏目录定位不同题型；无需卸载、清数据、导入替换备份或配置 AI。

当前“0.1.11 合成综合库”的名称来自既有测试数据，不是安装包版本。整库默认练习目录中，第 1–20 项为单选，第 21–24 项为多选，第 25–26 项为填空，第 27–28 项为背诵卡；另有 3 项背诵材料从模式页“背诵”进入。可直接用目录跳转，避免连续答完前面的长题。

| 编号 | 操作 | 本轮应达到的结果 |
| --- | --- | --- |
| 1 | 查看首页，打开题库、错题或统计后返回。 | 白底、黑字；次级文字和边框清楚；主按钮黑底白字，没有装饰阴影。题库、历史计数及原有继续进度仍在。 |
| 2 | 新练习 → 勾选范围 → 下一步；开关单选 / 多选等题型。 | 范围复选框的勾选 / 未勾选可辨；题型开关的开 / 关有明确黑白差异，题量照常更新。 |
| 3 | 进入一题选择题，先不选择，再点一个选项并切换。 | 未选时提交不可用，但文字仍清楚；选中项的黑底字母标识明显，切换后原选项恢复，提交可用。 |
| 4 | 长按一个选项排除，再次长按撤销。 | 排除时显示删除线和虚线，全文仍然清楚；撤销后恢复，长按本身不提交答案。 |
| 5 | 在合成题中故意答错一次；多选可选择 A、B 制造错选 / 漏选。 | 无需靠灰度猜测，能直接读到正确答案、错选、选对、漏选等结果；解析文字清楚。 |
| 6 | 打开背诵卡显示答案，或查看含公式的题目；展开更多并滚动。 | 题干、答案、解析及公式可读；底栏为实色，滚动经过底栏时没有下层文字透出来。 |
| 7 | 填空输入，或进入笔记 / 编辑但不保存，弹出并关闭键盘后返回。 | 输入文字、占位提示、按钮状态清楚；返回功能正常，已有内容未改变。如有键盘导航，焦点有黑色外框。 |
| 8 | 观察实际屏幕，退出再打开 Knoop。若平常使用系统深色模式，也在该模式下查看。 | 启动后仍是白底黑字，系统栏图标可辨，学习数据保留。记录本轮黑白样式的可读性、黑块是否过重，以及实物残影 / 闪烁感受。 |

目录与菜单间距、底栏动态留白、展开更多后的自动定位、搜索竞态和按屏阅读分别属于后续任务。本轮只解决视觉背景与状态，不把这些遗留项标为通过；用户仍可反馈任何新出现的遮挡或不可操作问题。
