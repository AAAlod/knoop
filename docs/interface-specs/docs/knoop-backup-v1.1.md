# Knoop Backup 1.1

1.1 在 [Backup 1.0](knoop-backup-v1.md) 的完整学习快照上新增 `ai_review_drafts`，共 13 张白名单表。新导出使用 1.1；公开结构见 [JSON Schema](../schemas/knoop-backup-v1.1.schema.json)。题库和 Bundle 协议保持原样。

待审核草稿必填列：`id`、`source_question_id`、`source_question_title`、`source_question_json`、`bank_json`、`model`、`generated_at`、`created_at`。原题快照、两道通过 AI 题库校验的候选、模型及生成时间随备份保存。原题可以已经删除；存在的原题仍须与快照的外部 ID 相符。草稿不属于正式题库，不产生正式作答。

读取 1.0 时，先用原 1.0 Schema 和原 SHA-256 验证文件，再显式迁移为 1.1：补入空 `ai_review_drafts` 及计数 0，重新计算迁移对象的 SHA-256，然后验证全部学习记录与引用。输入文件保持原样。不会猜测其他版本，也不会导出降级版：旧版应用无法读取 1.1，升级后应另存新备份。

白名单设置键、自增序列、完整性算法、事务恢复和恢复前安全副本规则与 1.0 相同。API Key 和 API 配置均不导出。恢复 1.0 时当前草稿也会被完整替换；确认页明确显示目标草稿数。

生成结果通过校验后先持久化为草稿，再展示保存为临时题组的操作。保存为题组与消费草稿处于同一事务；任一步失败均保留草稿。持久化失败时允许重试本机保存，不再次请求 AI；未成功保存前阻止离开或备份，用户仍可明确放弃结果。强制结束应用会丢失尚未持久化的候选。
