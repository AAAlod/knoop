# T11：紧凑布局与逐页截图

日期：2026-10-11。用户要求压缩各页面高度、减少滚动，优先解决首页「批量回炉」「AI 题组」被挤到屏幕外的问题。沿用逐项验收流程，本轮作为一个布局任务完成后等待用户手测。

## 修改前观察

已通过授权 PA6 依次截取首页、选择范围、选择模式、题目目录、题库管理、统计、完整备份、批量 AI 回炉、当前背诵、当前错题、练习方案、未完成、笔记、待返修、收藏、屏幕刷新和 AI 题组页。截图保存在 Git 忽略的 `artifacts/pa6-validation/compact-before-*.png`。

- 首页继续按钮下的进度独占一行，主操作及功能区之间留白较大；初始画面只能看到 AI 回炉标题，两个入口需要滚动。
- 选择模式的方式、开始、目录各占一行，刷题卡片挤占整屏，背诵操作需要下滚。
- 题库管理在 PA6 的宽度下仍强制把导出 / 删除放到下一行。
- 目录行高、统计卡片内边距、背诵标题与正文之间有可压缩的空白。
- 备份页已较紧凑；AI 配置卡片可收紧留白，但完整配置 / 批量选择表单和长题正文仍应正常滚动，不能隐藏内容来凑一屏。

截图与页面导航没有提交答案、翻到下一题、修改笔记、保存题库、恢复备份或调用在线 AI。

## 布局调整

- 首页将继续及进度放在同一个按钮内；PA6 宽度的其他功能采用三列，窄屏仍使用两列；减少组间留白和页面末尾的空滚动空间。AI 标题与两个入口保留。
- 选择模式的计数和方式同行，开始 / 目录同行；随机数量可显示，保存方案仍可展开，窄屏按内容自然换行。
- 主页面顶部留白收紧；没有固定操作栏的页面去掉多余底部预留，有固定栏的页面继续按实际栏高留白。
- 未完成列表将摘要和继续按钮同行，长范围名称自然换行；失效范围提示仍完整显示。
- 目录保留两行摘要与搜索能力，行高按内容增长；统计、阅读正文、题库管理和 AI 配置减少空白。触控区域保持至少 48 CSS 像素，正文与公式不裁剪。
