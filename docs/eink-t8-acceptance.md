- 收藏 / 取消收藏仅更新当前按钮，等待写入时拦截重复点击，失败不显示已保存状态。展开的更多菜单、题目、已有公式和阅读按钮保留；旧页面收藏写入完成后不会修改新题按钮。

- 未变化的错误提示保留原节点、消息滚动位置和重试忙碌状态，避免其他局部操作重复创建提示。保留 T7 的关闭、重试和成功反馈语义。
- 本轮减少应用的 DOM 替换及公式重复渲染；这些软件测量不能换算成实体墨水屏刷新次数。没有接入厂商刷新接口。

## 用户测试清单

1. **收藏与更多菜单**：进入长题，展开更多，阅读到中间，再收藏 / 取消收藏几次。菜单应保持展开且优先同行，阅读位置、已选 / 排除选项和公式横向位置不丢失。需要确认收藏保存时可退出再进入，测试结束恢复原收藏状态。
2. **填空与键盘**：在未提交的填空题中输入草稿，移动光标，再点收藏 / 取消收藏。检查键盘、草稿、光标和阅读位置保留；切换快刷也应保留草稿。不要为此重复提交答案。
3. **背诵 / 卡片展开**：阅读到较后位置再展开内容，答案及公式应完整、上屏 / 下屏仍可用，不回到题首或误跳下一题。切换快刷预览正常，已手动展开的内容继续保留。
4. **判分与下一题**：按平常方式完成单选 / 多选，以及有条件时的手动判分填空。检查选对、错选、漏选标识和答案正确，提交后不能继续改选；下一题解锁并从题首阅读。检查不会重复计分。
5. **临时题组与实际屏幕**：有现成临时题组时确认判分、下一题和草稿正常，无需在线生成。观察收藏、展开、判分时是否仍有异常跳动，以及实体屏幕残影 / 闪烁是否可接受；这些硬件表现只能由实物观察确认。

存储故障与重复操作已使用隔离数据库注入检查，用户无需在设备上制造故障。没有现成某类题目时可注明未测。ADB 截图只核对布局和内容，不证明实体刷新速度或残影改善。
