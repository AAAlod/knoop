# T2：旧 WebView 间距与触控布局验收

日期：2026-10-09。前置条件：用户明确确认 T1 通过。依据 [任务记录](eink-task-tracker.md) 的 T2 / Review R2；本轮仅处理间距、换行与触控尺寸。

## 本轮改动

- 顶栏题号与目录、选项字母与正文、范围复选框与名称、表单答案勾选与字母改用显式边距。
- 收藏 / 笔记 / 更多、更多菜单、审核常见问题及问题位置、题型和题库操作按钮在同排与换行后都有间距。
- 题库行、练习方案标题行和学习列表标题行使用旧 WebView 已支持的 Grid 间距；窄屏练习方案将标题与操作分行。
- 范围标签、答案标签、审核标签、方案与题库操作保持至少 48 CSS px 的触控高度，紧凑操作按钮保持至少 48 CSS px 宽度；批量导出按钮提高到 48px。
- 顶栏标题过长时只省略题号文本，保留目录提示和入口。

底栏 / 菜单遮挡与键盘可达性属于 T3；稳定顶栏属于 T5。本轮菜单仍可能需要滚动才能完整看到，不把间距修复当成这些问题已解决。

## 手动测试清单

使用设备上现有合成题库即可；编辑和审核页面可取消返回，无需保存。不要删除题库或清理学习数据。

1. **顶栏目录**：继续练习，题号与「目录」之间有清晰空隙；点击目录可以打开，返回后仍在原题。
2. **选项**：字母圆圈与正文分开，长选项换行不挤进圆圈；点击选项、长按排除 / 再长按取消的行为正常，不误触相邻项。
3. **题目操作与更多**：收藏、笔记、更多按钮之间分开；展开更多后，编辑 / 斩杀 / 标记问题之间有横向及换行间距。检查即可，不必执行斩杀。
4. **编辑与审核**：从更多进入编辑，答案勾选与 A / B 等字母分开，点击标签可切换；取消返回。进入标记问题，常见问题按钮、问题位置复选标签之间不粘连，勾选框与文字分开；取消返回。
5. **范围树与模式**：首页进入新练习，题库 / 章节的复选框与文字分开，折叠箭头和勾选互不误触；下一步后切换题型，按钮间距正常，换行时上下不相贴。
6. **题库与方案**：题库管理中的名称与操作分开，导出 / 删除按钮不相贴；有多个题库时检查导出复选框及「导出所选」。已有练习方案可检查长名称与开始 / 删除的间距，无需删除或新增方案。
7. **阅读与触摸**：检查以上页面没有新出现的横向裁字或难以点中的控件；若使用较大系统字号，再检查按钮换行后的间距。底栏遮挡请单独记录，交给 T3。
