# Knoop 0.2.0 Alpha：墨水屏适配更新

发布日期：2026-10-11。Tag：`v0.2.0-alpha`。

本版优先优化 Android 墨水屏学习体验，以汉王 Clear6 Plus（PA6）为首个适配目标。通用 Android 手机和平板适配计划于 2027 年推进。

## 更新内容

- **黑白可读**：白底黑字、高对比边框；选中、排除、正误和禁用状态通过文字、符号及边框表达，减少对颜色的依赖。
- **减少滚动**：首页继续与进度同行，功能入口更紧凑，PA6 上「批量回炉」「AI 题组」无需滚动即可看到；模式页的刷题与背诵操作同屏显示，未完成列表、目录、统计和阅读页收紧留白，保持触控区域与完整内容。
- **按屏阅读**：增加「上屏 / 下屏」，顶栏稳定、底栏按实际高度留白；编辑、笔记和目录往返保留阅读位置，新题从顶部开始。
- **稳定交互**：收藏、选项选择、判分和背诵展开使用局部更新，减少整页重建；保留公式、焦点、草稿与阅读位置。错误提示持续显示，失败保存可以手动重试。
- **旧 WebView 兼容**：补齐 UUID / JSON 克隆回退，修复 Flex 间距、搜索等待时的过期操作；支持中文组合输入与大题量分批目录。
- **手动全屏刷新**：首页新增「屏幕刷新」。在已验证的 PA6 / Android 11 增量固件 `eng.hanvon.20250524.095811` 上可手动请求全屏刷新；其他设备或固件降级为系统默认刷新。此功能不修改系统全局模式。

## 安装与升级

- 版本 `0.2.0`，Android versionCode `114`；Git tag 使用 `v0.2.0-alpha` 表明 Alpha 阶段。
- 签名 Release 文件：`knoop-v0.2.0-arm64-release.apk`，仅支持 `arm64-v8a`。
- APK SHA-256：`a6f511d09d23a488fdef5a2d4c27d8840f9b00f06a2798bc0d07d0c177c65860`，随包提供 `.sha256` 校验文件。
- 沿用原应用 ID、签名、数据库与题库 / 备份格式，支持直接覆盖升级。重要学习数据可通过首页「备份与恢复」另存到应用外部。

## 已知限制

- 日常闪烁仍存在；减少 DOM 重建不等于降低实体墨水屏刷新次数，尚无已验证的自动局刷方案。
- PA6 手动全屏刷新已由用户观察确认全屏闪黑，但残影改善尚未确认；支持范围仅限上述设备与固件。
- 当前 PA6 没有机身翻页键，使用触屏按屏阅读。其他设备、大字号及键盘的实际使用体验仍需持续验证。
- 本版仍处于 Alpha 阶段；自动检查和截图不能替代实体屏体验及用户手动验收。
