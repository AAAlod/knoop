## 0.1.12-alpha

- 精简首页、练习、搜索及 AI 操作文案，保留总内容等独立计数；错题和统计口径收纳至“统计规则”。
- 题型选择移至组题页并即时显示题量；保存方案复用本次方式、类型与随机数量，修复方案默认数量不一致。范围底栏去除内部节点计数，目录明确“从此题开始 / 跳至此题”。
- AI 状态区分“格式通过 / 待核对 / 已保存”，保存前保留人工核对、正式题库隔离及 API 费用提示。
- 首页突出“继续 / 新练习”，空库仅保留导入；最近方案及题库、统计、备份等入口弱化显示，保留已有 AI 内容的入口。
- 答题页保留收藏、笔记直达，编辑、斩杀、标记问题进入“更多”；正式与 AI 选项结果增加“选对 / 错选 / 漏选 / 正确答案”标识及选择状态，不再仅靠颜色区分。
- 保留原题库协议、应用 ID、数据库和签名；本版提供 Android ARM64 Release APK。自动回归与原签名构建验证通过，Android 真机覆盖安装、大字体、键盘与旋转仍待验收。
