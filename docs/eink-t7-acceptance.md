## 改动

- 通用错误不再四秒后消失，放在顶栏下的黑白提示区，正文按实际顶栏高度避让。提示可关闭；长消息可以在消息区域滚动。正常无消息时不新增占位行。
- 不同来源的错误依次保留，关闭当前错误后显示下一条。成功提示不会覆盖待处理错误；明确重试同一操作时替换对应旧错误。提示仅在本次应用运行中保留，不写入数据库或备份。
- 成功消息优先放在当前底部操作区，没有底栏时放在表单消息区、相关操作或返回页面中，保持可读至下一次操作或手动关闭；底栏按实际高度留白，不使用定时消失的悬浮遮挡。现有收藏按钮、判分结果等自身状态继续作为反馈。
- 正式 / 临时答案草稿保存失败时保留输入和选择，提供「重试保存」。该按钮仅重试本机待保存草稿，不提交答案或调用 AI；关闭提示不会丢弃写入队列，离开页面仍须通过原有保存检查。
- 编辑、笔记和审核保存时保留输入内容，按钮显示「保存中…」并拦截重复操作；作答保存维持原有忙碌保护，并显示「处理中…」。失败后恢复按钮及可重试路径。统一等待按钮返回的异步操作，避免失败绕过错误反馈。
- 原有 AI 草稿保存、批次错误及备份恢复的持久状态和专用恢复入口继续保留。T7 不接入新的刷新接口，也不实施 T8 的题目局部更新。

## 用户测试清单

1. **可读错误与关闭**：进入任一题的编辑，暂时清空必填的题干 / 提示后点保存。错误应保持至少十秒，顶部返回和底部保存仍可操作，正文不被提示盖住。关闭提示后输入仍保留；取消编辑可以保留原题。
2. **修正后重试**：将上述字段恢复为有效内容再保存。旧错误消失，返回页面出现「已保存」等成功消息；该提示不悬浮遮挡题目，下一次操作或手动关闭后消失。
3. **笔记与审核**：保存已有笔记（可不改内容），检查返回后反馈可读、结果正确。需要保存审核时同样检查；不要仅为验收改变题目的审核状态。保存较快时可能来不及看到忙碌文案，不据此判失败。
4. **长页、键盘和大字**：有错误提示时滑动长表单，打开 / 关闭键盘，确认提示、输入区、关闭和保存操作可达，内容没有被顶栏或底栏挡住。长错误消息应可在提示内滚动。
5. **正常阅读回归**：关闭提示后，长题 / 背诵的上屏、下屏和作答按钮正常，布局不留下空白提示行。选择、草稿和已有进度仍保留。

存储故障、判分失败、草稿重试和重复保存由开发侧使用隔离 SQLite 注入检查，用户无需在设备上制造故障。若实际遇到「答案草稿未保存」，应能重试保存；失败继续显示原因，成功后不增加答题统计。没有现成 AI 临时题组时无需在线生成。

自动化浏览器不能代替 PA6 WebView 83 / 汉王输入法验收；实体墨水屏残影、闪烁和刷新速度由用户观察，ADB 截图不验证这些指标。
