## 问题与改动

修改前使用隔离合成长题测量：实际页面滚动根为 HTML，`window.scrollY=900` 时顶栏 `top=-900`；BODY 和 `#app` 因 `overflow-x:hidden` 计算出了纵向 `auto`，顶栏依附于未实际滚动的祖先。原始截图为 `artifacts/eink-t5/browser-before/header-scrolled.png`。

- 顶栏改为固定在视口上方，移除 BODY / `#app` 上多余的滚动祖先。页面继续通过 window / document 滚动，宽公式维持自身横向滚动。
- 按顶栏实际高度预留正文空间，字号或顶栏尺寸变化时重新测量。输入框避让同时考虑顶栏、底栏及键盘可用区域。
- 正式会话按「会话 + 具体题目」、临时题组按「题组 + 序号 + 题目」保存阅读位置。同题判分、显示答案、收藏更新以及从编辑 / 笔记 / 审核 / 目录返回时，优先恢复可见文段或选项相对顶栏的位置，找不到该内容时回退到原滚动距离并由页面范围限制位置。
- 编辑等新页面从顶部进入，不自动弹出键盘。下一题 / 下一项、完成页、明确的目录跳题和重新开始从顶部显示；继续现有题目可恢复本次运行内的位置。
- 公式字体加载后的补偿不会覆盖后续用户手势或新页面。阅读位置是内存中的临时 UI 状态，最多保留 200 条，应用重启后不恢复；不写入数据库、判分、进度或备份协议。

## 用户测试清单

使用现有题库即可，无需重新导入。阅读位置测试在同一次应用运行中进行。

1. **稳定顶栏**：打开长题、长背诵或长表单，连续向下滚动。返回按钮、题号 / 目录、快刷等现有顶栏操作应持续可见且可点，正文起始处不被遮住；宽公式仍可单独左右查看。
2. **编辑与返回**：在题目下方进入编辑，应从第一个字段开始且不自动弹键盘。取消或保存后返回同题，尽量回到原文段 / 选项，而非编辑页面的滚动位置；原答案草稿保留。笔记和审核往返同样检查。
3. **同题与新题**：显示答案 / 背诵内容或提交后，留在当前题的合理阅读位置；点击下一题 / 下一项后回到新题顶部，首行可见。仅滚动、打开目录或往返表单不增加答题统计。
4. **目录往返**：从滚到中段的题目打开目录，直接返回应恢复题目位置；明确点选题目或输入题号跳转则从题首显示，包括跳到当前同一道题。
5. **字号与键盘**：如使用大字，或在编辑末字段打开 / 关闭键盘，确认顶栏、输入框、保存栏各自可达，正文和字段没有被顶栏或底栏挡住。
6. **AI 临时题组（已有时）**：同题判分保留位置，返回题组列表再继续恢复阅读，下一题回顶部；不会增加正式题库答题统计。设备没有已有题组时跳过，不需为验收调用在线 AI；开发侧已用隔离合成题组回归。

保存编辑后若删除了原阅读段落，或返回后的内容变短，允许回退到附近可用位置；不能停在空白页或不可达区域。
