# Knoop 0.1.12 Android 真机检查清单

测试包：`artifacts/knoop-v0.1.12-arm64-release.apk`，versionCode 113。
本页全部真机项目仍为“未测试”；桌面浏览器截图、自动化与签名检查不能替代实机验收。

## 准备

1. 在 0.1.11 的“题库 → 完整备份 / 恢复”导出完整备份，另存到应用外部；确认备份文件可见。
2. 覆盖安装 0.1.12，不卸载、不清数据。确认题库、作答、笔记、收藏、未完成进度和旧练习方案保留。
3. 使用上一轮合成包 `artifacts/knoop-0.1.11-device-test-kit.zip`；协议未变，可直接复用。内容均为模拟测试数据。详见 `docs/device-test-checklist-0.1.11.md` 的导入/恢复风险和基准计数。
4. UI 首选 `01-basic-bank.json`（所有题型、长题与公式）、`03-memo-only-bank.json`、`06-stress-1000.json`；AI 页面可在隔离测试环境用 `07-offline-learning-backup-v1.1.json` 查看离线草稿/题组/批次。恢复会替换全部学习状态，请先备份并保留恢复前副本。

## Android 布局与系统交互

- 在小屏、正常屏与大屏检查（桌面参考宽度 320 / 360 / 390 / 480）；系统字体设为较大/最大，检查首页、模式页、目录、更多菜单、正误选项、AI 页面。
- 横竖屏切换，检查长题、公式局部滚动、底部提交/下一题/完成；可滚至最后内容，没有不可点击或被裁切的控件。
- 在填空、搜索、方案名称、编辑、笔记和 API Key 输入时弹出软键盘，检查最后输入区、确认按钮与固定底栏可达；返回关闭键盘后焦点与草稿保留。
- TalkBack 检查题型开关状态、选择状态、目录条目意图、“更多”的展开/收起和结果文字。
- 导入前预览及覆盖确认、恢复前安全副本及替换确认、斩杀/删除确认仍可见。恢复操作先在有外部备份的测试环境进行。

记录时请附设备型号、Android 版本、系统字体/显示缩放、操作步骤和结果。下一阶段优先修复这些真机反馈；通过后再决定是否发布 0.1.12-alpha。
